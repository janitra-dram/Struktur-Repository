# 2EZ4U APP

Proyek Akhir Struktur Data & Analisa Algoritma.

## Struktur Folder
- `data/`: berisi data CSV (200.000 baris pesanan & peta).
- `backend/`: berisi logika struktur data buatan sendiri.
- `frontend/`: antarmuka aplikasi dengan Tkinter.
- `app.py`: entry point untuk menjalankan aplikasi.

## Cara Menjalankan
```bash
python app.py
```
